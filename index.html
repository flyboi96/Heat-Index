Heat Index Challenge

Track strength, conditioning, and performance. Log PRs anytime. Build your score. Compete in the heat.

Challenge Overview

  1. Test five events: squat, incline bench, pull-ups / dead-bar hang, 40-meter dash, and the 1.64-mile run / 2000m row.
  2. Only scores achieved during this deployment count toward the challenge.
  3. Each event is evenly weighted. Strong across all five beats being elite at just one.
  4. No single test day. Log a PR whenever you earn one.

How to Compete

  1. Open the Score tab.
  2. Select your last name, then enter only the PRs you want to change.
  3. Tap Preview Heat Index to see what your score would be before uploading anything.
  4. Tap Upload PRs to Leaderboard to save those numbers to the live leaderboard. Blank fields leave your old PRs unchanged.
  5. Tap Save Form on This Device to keep your current entries on your phone or browser. Tap Load Saved Form from This Device to bring them back later.

How Scoring Works

  1. Each event scores from 0 to 100 based on where you fall between the standards.
  2. Cub = 20, Gazelle = 40, Leopard = 60, Lion = 80, Mamba = 100.
  3. The early tiers are intentionally more attainable so people can get on the board fast and build momentum.
  4. Mamba is meant to be achievable for someone who is legitimately very fit out here, not just a specialist.
  5. You can score above Mamba, so there is always room to improve.
  6. Your final Heat Index score is the average of all five event scores.

Challenge Rules

  1. Only scores achieved during this deployment count toward the challenge and leaderboard.
  2. Strength events (squat and incline bench) use allometric bodyweight scaling so heavier athletes are not required to lift pound-for-pound more.
  3. Incline bench can use a barbell. Women may use dumbbells; enter the total dumbbell load.
  4. Pull-Ups / Dead-Bar Hang: men perform strict pull-ups, women perform a dead-bar hang. Bodyweight and added weight count through the same allometric load scaling.
  5. Speed / power event: 40-meter dash from a standing start. Another person must time it.
  6. Conditioning event: 1.64-mile run or 2000m row. Use whichever gives the higher score. Row standards are intentionally tougher because the challenge prioritizes running in heat and field conditions.
  7. Each event is worth 20 points per tier: Cub 20, Gazelle 40, Leopard 60, Lion 80, Mamba 100.
  8. No ceiling. Scores continue past Mamba. Keep pushing.

What Counts

  1. Squat: below parallel, controlled, and clearly completed for 3 reps.
  2. Incline bench: controlled lower, full lockout, and no excessive bounce. Dumbbell scores use combined dumbbell weight.
  3. Pull-ups: dead hang to chin clearly over bar. No kipping.
  4. Dead-bar hang: full grip, feet off ground, no touching down.
  5. 40-meter dash: another person must time it. Run the full distance between light poles on the running track.
  6. Run / row: No stopping the clock until the event is complete.

Run Route

Start at the marked start/finish point, run to the turnaround point, then return to start. That out-and-back is 0.82 miles total. Repeat the same out-and-back one more time for 1.64 miles total. The route is just south of the soccer field/NEX.

Why This Scale

These standards are built to reward balanced fitness across strength, grip, upper-body endurance, speed, and conditioning - not just one specialty.

Allometric Strength Scaling

  1. Reference bodyweight is 180 lb for men and 140 lb for women.
  2. Allometric bodyweight = bodyweight^0.67 x reference bodyweight^0.33.
  3. Squat and incline bench score value = lift divided by allometric bodyweight.
  4. Pull-up / hang score value = actual result x (bodyweight + added weight) divided by allometric bodyweight.

Research basis: Folland, McCauley, and Williams recommend allometric scaling for comparing strength measures across body sizes in European Journal of Applied Physiology, 2008.
